# Concert & Event Log (เวอร์ชันเก็บในเครื่อง + สำรองลง Google Drive)

ไม่ต้องล็อกอิน ไม่ต้องตั้งค่า Google Cloud
ข้อมูลเก็บในเบราว์เซอร์ของมือถือแต่ละเครื่อง ใครเปิดในมือถือตัวเองก็ได้ข้อมูลแยกกันอัตโนมัติ

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.webmanifest`, `icons/` | ชื่อแอปและไอคอนตอนติดตั้งลงหน้าจอ |
| `sw.js` | ให้เปิดแอปได้ตอนไม่มีเน็ต |

## ติดตั้งลงมือถือ

1. เปิดลิงก์ใน **Chrome**
2. กด ⋮ → **Install app** (หรือ **Add to Home screen**)
3. จะได้ไอคอนรูปตั๋ว เปิดแบบเต็มจอเหมือนแอป

## การสำรองข้อมูล (สำคัญ)

ข้อมูลอยู่ในเบราว์เซอร์ของมือถือเท่านั้น ถ้าล้างข้อมูล Chrome ถอนแอป หรือเปลี่ยนเครื่อง ข้อมูลจะหาย

**สำรองลง Google Drive**
1. แตะไอคอนเมฆ → **Back up to Google Drive**
2. เมนูแชร์ของมือถือจะเปิดขึ้น เลือก **Drive** เลือกโฟลเดอร์ แล้วกด **Save**
3. ไฟล์ชื่อ `concert-log-backup-YYYY-MM-DD.txt` (ข้างในเป็น JSON ที่มีรูปปกครบ ที่ต้องเป็น .txt เพราะ Chrome แชร์ไฟล์ .json ไม่ได้)

**คืนข้อมูล**
แตะไอคอนเมฆ → **Restore from a backup file** → เลือกไฟล์จาก Drive หรือ Downloads
- งานเดียวกันจะถูกแทนด้วยข้อมูลในไฟล์
- งานอื่นที่อยู่ในเครื่องยังอยู่ครบ

**ตัวเตือน**
- ถ้ามีการแก้ไขและไม่ได้สำรองเกิน 7 วัน จะมีแถบเตือนขึ้นใต้หัวข้อ แตะ **Back up** ได้ทันที
- จุดแดงที่ไอคอนเมฆ แปลว่ามีข้อมูลที่ยังไม่ได้สำรอง

## นับถอยหลังและแจ้งเตือน

- **Next up:** หน้าแรกมีการ์ดงานที่ใกล้ที่สุด นับถอยหลังเป็นวัน ชั่วโมง นาที วินาที (ถ้าไม่ได้ใส่เวลาเริ่ม จะนับเป็นวัน)
- **Notify me** (ในหน้า Details ของงานที่ยังไม่ถึง): เลือกได้ 1 day / 3 hours / 1 hour before ถ้างานไม่มีเวลาเริ่ม จะเป็น Day before 9:00 / On the day 9:00
  - ครั้งแรกจะถามสิทธิ์แจ้งเตือน ให้กด Allow
  - ตอนเปิดแอปอยู่ แจ้งเตือนจะขึ้นตรงเวลา
  - ตอนปิดแอป Android จะปลุกแอปมาเช็กเป็นระยะ (ต้องติดตั้งแอปลงหน้าจอก่อน) อาจมาช้ากว่ากำหนด
- **Add to Google Calendar:** ถ้าอยากได้แจ้งเตือนที่ไม่พลาดแน่นอน กดปุ่มนี้ในหน้า Details จะเปิด Google Calendar พร้อมกรอกชื่องาน เวลา สถานที่ และที่นั่งให้แล้ว กด Save

## ล้างข้อมูลทั้งหมด

แตะไอคอนเมฆ → **Delete all tickets on this phone** แล้วแตะซ้ำอีกครั้งเพื่อยืนยัน
- ครั้งแรกจะบอกจำนวนงานที่จะลบ และเตือนถ้ายังไม่ได้ backup
- ลบเฉพาะข้อมูลในมือถือเครื่องนั้น ไฟล์ backup ที่อยู่ใน Drive ยังอยู่ครบ

## รูปบัตรตัวจริง

ในหน้า Edit มีส่วน **Ticket photos**
- **Take photo** เปิดกล้องถ่ายบัตรได้เลย หรือ **Choose photo** เลือกจากแกลเลอรี ได้สูงสุด 4 รูปต่องาน (เช่น หน้าและหลังบัตร)
- ในหน้า Details แตะรูปเพื่อดูเต็มจอ แตะรูปอีกครั้งเพื่อซูม ปัดซ้ายขวาเพื่อดูรูปถัดไป
- รูปบัตรรวมอยู่ในไฟล์ Backup ด้วย ไฟล์จะใหญ่ขึ้นตามจำนวนรูป
- ถ้าบัตรมี QR code อย่าแชร์รูปหรือไฟล์ backup ก่อนวันงาน

## โลโก้ในตราประทับ

ในหน้า Edit ส่วน **Stamp logo** กด **Upload logo** แล้วเลือกรูปโลโก้ของศิลปิน
- แอปจะแปลงโลโก้เป็นหมึกสีขาวให้เข้ากับตรา (รูป PNG พื้นใสได้ผลดีที่สุด รูปพื้นขาวหรือพื้นดำก็ใช้ได้)
- ใช้กับทุกงานของศิลปินชื่อนั้นอัตโนมัติ ไม่สนตัวพิมพ์เล็กใหญ่และช่องว่าง เช่น EmiBonnie กับ Emi Bonnie
- กด **Remove logo** เพื่อกลับไปใช้ข้อความแบบเดิม

## ข้อควรรู้

- **ฟีเจอร์ที่ไม่มีในเวอร์ชันนี้:** Find shows และการหาพิกัดจากชื่อสถานที่
- **ไม่ซิงก์ข้ามเครื่องอัตโนมัติ:** ถ้าจะย้ายเครื่อง ให้ Back up จากเครื่องเก่า แล้ว Restore ในเครื่องใหม่
